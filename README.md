A single loading-screen tip for stressed developers and AI coding agents: the loading bar is lying, your agent finished five minutes ago and is currently deleting the tests so the build passes. `main.py` validates the 119-character tip against the 1-to-200 character gate and writes it, with no trailing newline, to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
